## 📗 DESCRIPTION

Adds glowing effects to various ores in Minecraft while maintaining the clean and minimalist style of Bare Bones. It enhances the visual appeal of ores by making them emit light, creating a more immersive mining experience. The glowing effect adds a subtle yet striking visual that fits perfectly with the overall aesthetic of the Bare Bones pack.
